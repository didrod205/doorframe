Can other agents walk through your door?

Paste your site. Doorframe reads its agent-manifest.json, network and links.json the way a peer site would, checks them against the Minimum Viable Specification section by section, draws your agent network and follows your peer links. It runs in your browser and needs no key.

Ask the desk

An agent network that checks agent networks

The Doorframe desk is this site's own open agent network: a front desk, a conformance auditor that runs the checker through site actions, a fix writer, and a spec reference that lives on another origin and loads into your browser after you approve it. Your LLM key stays in this browser and goes only to the router you pick.

Loading the desk...

Call the desk from your own network

Any open agentic website can load the desk as a peer network. Add a link slot to your network and bind it in your links.json:

{
  "version": 1,
  "networks": {
    "your_network": { "conformance_desk": "" }
  }
}

The desk then runs in your visitor's browser with your router and their key, never ours.

Same checks in a terminal or CI

git clone https://github.com/didrod205/doorframe
node doorframe/cli/doorframe.mjs https://your-site.example/agents/
# exit code 1 when any check fails

The CLI reads response headers directly, so it reports the exact Access-Control-Allow-Origin value a browser would see.

Doorframe checks against the Minimum Viable Specification for a Worldwide Agentic Web. Structural validation and the desk use the reference browser runtime from that repository (Apache-2.0). A check result is a technical reading of public files, not an official judgment.
